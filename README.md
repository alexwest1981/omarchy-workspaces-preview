# Omarchy Workspaces Preview & Native Task Switcher 🖥️✨

A powerful and elegant plugin for **[Omarchy](https://omarchy.org)** / **Hyprland** featuring:
1. 🖱️ **Status Bar Workspace Indicator & Hover Preview**
2. 🪟 **macOS-Style Live Window Task Switcher (`Super + Tab` / `Super + Alt + W`)** with live screencopy previews, app icons, and workspace info.
3. ⌨️ **Terminal TUI Mode fallback (`omarchy-workspaces-picker --tui`)**

---

## ⚡ 1-Line Super-Easy Install (För din kompis)

Kör bara detta enda kommando i terminalen:

```bash
curl -sL https://raw.githubusercontent.com/alexwest1981/omarchy-workspaces-preview/main/install.sh | bash
```

Detta skript fixar **allt automatiskt**:
✔ Laddar ned / uppdaterar pluginet  
✔ Lägger till kortkommandon i `~/.config/hypr/bindings.lua`  
✔ Aktiverar pluginet i `~/.config/omarchy/config.json`  
✔ Startar om panelen och laddar om Hyprland  

---

## ⌨️ Användning

- **Snabbväxla appar (`Super + Tab`):** Håll in <kbd>Super</kbd> och tryck <kbd>Tab</kbd> för att stega mellan öppna appar. Släpp <kbd>Super</kbd> för att direkt byta fönster.
- **Fönsteröversikt (`Super + Alt + W`):** Öppnar översikten i klickbart läge som stannar öppen tills du klickar på en app eller trycker <kbd>Enter</kbd> / <kbd>Escape</kbd>.
- **Stäng app:** Tryck <kbd>Super</kbd> + <kbd>Q</kbd> (eller <kbd>Q</kbd>) medan översikten är öppen för att stänga den markerade appen direkt.
- **Mus & tangentbord:** Klicka på valfritt fönster eller navigera med piltangenterna / Tab.
